# 我写了个免费开源的 GitHub 中文浏览器，项目名/简介/README 一键翻译

> 逛 GitHub 看到好项目，点进去发现 README 全是英文，浏览器翻译插件又只能整页粗暴翻译——这大概是每个中文开发者的日常痛点。既然没有趁手的工具，那就自己做一个。

## 为什么会有这个项目

GitHub 上有超过 4 亿个仓库，其中大量的优质开源项目只提供英文文档。对于英文不太友好的开发者来说：

- **发现难**：GitHub Trending 榜单没有中文翻译，项目简介看不懂
- **阅读难**：README 里的技术说明、使用教程，逐段复制到翻译工具效率太低
- **门槛高**：市面上能翻译 README 的工具，要么付费，要么需要自己申请各种 API Key

所以我自己动手，用 **Python + PyQt6** 写了一个桌面应用——**GitHub 开源项目浏览器**。

---

## 这个工具能做什么

### 1. 发现页：按星星数量排序，滚动加载更多

启动后自动从 GitHub Search API 拉取高星项目，**统一按星星数量降序展示**。往下滚动到底部自动加载更多（每页 50 条，无上限），追加的数据会与已有列表排序完美衔接。

还内置了领域分类：AI、前端、后端、移动端、DevOps、安全……想快速看某个方向的高星项目，点一下分类就行。

> 📷 【插图位置】discover.png（发现页截图）

### 2. 趋势热榜：官方榜单 + 中文翻译 + 涨跌标记

直接抓取 `github.com/trending` 官方榜单，支持当日 / 本周 / 本月切换，展示新增星星数量和排名涨跌（🔺 上升 / 🔻 下降 / 🆕 新上榜）。

更关键的是：**翻译完成后，官方排名和涨跌前缀不会被翻译结果覆盖**——你可以既看中文介绍，又不丢失原始榜单信息。

> 📷 【插图位置】trending.png（趋势热榜截图）

### 3. 多引擎智能翻译：全免费、零配置、自动回退

这是整个工具的核心卖点：

| 引擎 | 特点 | 需要 |
|------|------|------|
| **微软 Edge 翻译** | 免 Key、国内直连 | 无 |
| **Google 翻译** | 质量稳定、免费 | 可访问外网 |
| **本地术语词典** | 1900+ 技术词条，永不失败 | 无 |

- **无需任何 API Key**，装上就能用
- 默认优先 Edge（国内直连），失败自动回退 Google → 本地词典，全程无感知
- 翻译结果走 **SQLite 缓存 + 本地记忆库**（30 天 TTL），二次打开秒开
- **列表翻译 / 详情翻译分离线程池**，切换项目或视图时自动取消在途翻译，界面不会卡住

项目名、项目简介、README 一键全翻译成中文。README 里的图片也会自动嵌入，翻译后排版不丢失。

> 📷 【插图位置】detail.png（项目详情 / README 翻译截图）

### 4. 收藏 / 历史 / 系统托盘

- 收藏夹和浏览历史保存在本地，**收藏页列表同样支持自动翻译**
- 点击关闭按钮最小化到系统托盘，后台常驻，双击恢复
- 深色 / 浅色主题，中英文界面，窗口缩放自适应
- GitHub Token 使用 **Windows DPAPI 加密**落盘，不担心明文泄露

> 📷 【插图位置】settings.png（设置页截图）

## 技术实现（写给开发者的部分）

- **PyQt6 多线程架构**：列表翻译、详情翻译、README 图片嵌入使用独立线程池，切换视图通过"代际号"机制优雅取消在途任务，不占用 UI 线程
- **SQLite 存储**：翻译缓存、翻译记忆库、排名历史、学习词条
- **PyInstaller + GitHub Actions**：推送 tag 自动构建 exe 并发布 Release，一键发布
- **插件系统**：支持自定义插件扩展功能

## 快速开始

**下载即用，无需安装 Python：**

👉 [下载最新版 GitHub.exe](https://github.com/chenyang3333333/github-open-source-browser/releases/latest)

如果你想从源码运行：

```bash
git clone https://github.com/chenyang3333333/github-open-source-browser.git
cd github-open-source-browser
pip install -r requirements.txt
python run_app.py --run
```

打包成 exe：

```bash
python run_app.py --buildexe
```

### 上传步骤

1. 登录掘金 → 新建文章（Markdown 模式）
2. 光标移到目标位置 → 点击编辑器工具栏**图片图标**（或直接拖拽图片到编辑区）
3. 按上表顺序逐张上传，上传后自动插入图床链接
4. 选中图片可调整宽度，建议统一 900px 保持排版整齐

**推荐顺序（从文首到文末）**：`demo.gif → discover.png → trending.png → detail.png → settings.png`

- 掘金单图上限 5MB，本套素材全部达标（最大 demo.gif 2.5MB），无需压缩
